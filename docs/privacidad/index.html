Solicitudes de catering

Tu nombre, WhatsApp y los datos que compartas sobre tu reunión se utilizan para preparar una propuesta y coordinar contigo. El correo electrónico es opcional. La solicitud no confirma una reserva ni te suscribe a publicidad.

El formulario de catering utiliza FormSubmit para enviar la información a mabellramospe@gmail.com. El proveedor conserva un respaldo de los envíos durante 30 días. Puedes consultar sus condiciones de privacidad. Para solicitar acceso, corrección o eliminación de tus datos, escribe a mabellramospe@gmail.com.

La copia recibida en el correo del negocio se utiliza para atender y dar seguimiento a tu solicitud; no se publica en esta web. Si eliges WhatsApp, el mensaje se abrirá para que lo revises antes de enviarlo.

Uso de esta web

No se crean cuentas de clientes ni se realizan pagos desde esta página. No utilizamos cookies publicitarias ni incorporamos seguimiento comercial. Si se activa la protección del formulario, su proveedor verificará el envío para limitar el abuso.
